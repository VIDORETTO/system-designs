O sistema tem contraste forte, mas não depende só dele.

A extração separa o que foi observado na origem do que é recomendação para uma implementação robusta.

Observed baseline

✓
Landmarks and headings

banner, navigation, main, complementary, contentinfo, h1–h3.

✓
Pressed states

chips and themes expose aria-pressed and visible selection.

✓
Focus-visible

2px accent outline with 2px offset measured on the use-case control.

✓
Reduced motion branch

source CSS collapses animation and transition durations to 0.001ms.

Recommendations

→
Announce live state

use a polite live region when a case changes prompt and agent statuses.

→
Keep labels with color

dots and accent should reinforce a text status, never replace it.

→
Describe meaningful proof art

decorative art can remain hidden; a product screenshot needs a useful alt.

recommended The source uses muted hairlines as atmosphere. Keep them decorative when text or state is essential.
