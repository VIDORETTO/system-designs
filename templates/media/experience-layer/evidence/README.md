# Evidence · Experience layer fixture

This fixture is intentionally neutral. The SVGs are local poster/still aids for
the report preview, not copies of a protected brand asset.

## Evidence map

| ID | Artifact | What it supports |
| --- | --- | --- |
| E-live-home-desktop-001 | desktop capture reference | hero hierarchy, tokens, grid and primary action |
| E-live-home-mobile-001 | mobile capture reference | reflow, crop protection and navigation substitution |
| E-runtime-hero-media-001 | authorized recording reference | playback/composition relationship and focal moment |
| E-source-runtime-probe-001 | runtime probe reference | media/resource/effect inventory limitations |

The manifest does not embed the source video. When an authorized file is
available, run skill/scripts/extract_video_frames.py and keep the generated
frame manifest next to the evidence.
